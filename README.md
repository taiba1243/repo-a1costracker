                    # PYTHON PROJECT

## project Description:

One script sends the same prompt to two providers, one of them free. For each, print the reply, input and output tokens, and the cost of the call.

## How To Run It:

* ***clone the repository.***
* ***install required dependencies. (google-genai, groq).***
* ***add API keys in .env file.***
* ***run the scrip.***
